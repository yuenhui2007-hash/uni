💡 Key Point

The accounting cycle is a continuous process. Closing entries reset temporary accounts (revenues, expenses, dividends) to zero for the next period, while permanent accounts (assets, liabilities, equity) carry forward.

Key Formulas

Essential equations for quick reference

Time Value of Money
Future Value
FV = PV × (1 + r)n
Present Value
PV = FV / (1 + r)n
Annuity PV
PV = PMT × [(1 - (1 + r)-n) / r]
Capital Budgeting
NPV
NPV = Σ(CFt / (1 + r)t) - Initial Investment
IRR
NPV = 0 = Σ(CFt / (1 + IRR)t) - Initial Investment
